# Templo de Luz — Cartas Psicografadas

Aplicação web do projeto Templo de Luz para solicitação e psicografia de cartas mediúnicas.

## Tecnologias

- **Framework**: [TanStack Start](https://tanstack.com/start) / React 19
- **Roteamento**: [TanStack Router](https://tanstack.com/router)
- **Estilização**: Tailwind CSS v4 & Lucide Icons
- **Componentes**: Radix UI / Shadcn UI

## Como Executar Localmente

1. Instale as dependências:

   ```bash
   bun install
   ```

   _(ou `npm install`)_

2. Inicie o servidor de desenvolvimento:

   ```bash
   bun run dev
   ```

   _(ou `npm run dev`)_

3. Para gerar a build de produção:
   ```bash
   bun run build
   ```
